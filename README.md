## What is Quest Board?

Quest Board is a todo app that makes staying organized feel a little more fun. Add your tasks as "quests" with a deadline and a tag. Save resource links (articles, YouTube videos, anything) with a title so they're easy to find later, all sorted into your own sections. Everything is tracked to your account, with a profile page showing exactly how many quests you have left, how many you've finished, and a streak that counts how many days in a row you've logged in.

## Features

- 🚀 **One-click sign-in** — just sign in with your Gmail account, no passwords
- 🗡️ **Todo list with deadlines and tags** — add a due date and a category (Study, Personal, Project, Other) to every quest
- 📚 **Resources** — save links (including YouTube) with a title, organized into your own sections
- 🏆 **Archive** — see every todo you've already completed, grouped by day
- 👤 **Profile** — tracks how many quests you have left, how many you've completed, and your daily login streak
- 🤖 **AI assistant** — a built-in chat assistant to help you plan, brainstorm, or answer questions
- 🌙 **Dark mode** — toggle it from the nav

## Tech stack

- Framework: Next.js (App Router, React)
- Language: TypeScript
- Auth: NextAuth.js with Google OAuth
- Database: PostgreSQL
- ORM: Prisma
- AI: Google Gemini API
- CSS: Plain custom CSS, no UI framework
- Hosting: Vercel + Neon (PostgreSQL)
